# Release packets

This directory contains compact, machine-readable evidence packets for tagged Badger Sprawl Runner releases.

These files are deliberately separate from the dated `release-evidence/YYYY-MM-DD/` campaign-certification trees. The dated trees contain heavyweight browser recordings, traces, screenshots, accessibility evidence, migration evidence, and deterministic benchmark material generated by the release-evidence tooling. The packets here record the software-release boundary itself: release revisions, version agreement, verification commands and outcomes, artifact hashes, known caveats, tag state, and publication state.

A packet may be committed after its corresponding local tag so that the tag continues to identify the exact tested release-content snapshot. Post-release evidence commits must not silently move an existing tag.

Validate a packet against its recorded target without requiring the tag ref:

```sh
pnpm run release:packet:check -- --packet release-evidence/releases/v1.5.1.json --target 02fb9d465bf3293763e4f38cc24a409cfd70cf5c
```

For a real tag gate, pass `--tag vMAJOR.MINOR.PATCH`. This additionally requires an annotated local tag and verifies the tag object and peeled commit before checking the tagged tree, first parent, subject, release-member package metadata, release train, vendored Runtime compatibility, and dated changelog section. GitHub tag CI obtains the packet from `origin/main`, so publish the post-release evidence commit on `main` before pushing the corresponding tag.
